## Ghostfolio Release Notes

### [`v3.98.0`](https://redirect.github.com/ghostfolio/ghostfolio/blob/HEAD/CHANGELOG.md#3980---2026-11-04)

[Compare Source](https://redirect.github.com/ghostfolio/ghostfolio/compare/3.97.0...3.98.0)

##### Changed

- Improved the content of the pricing page
- Changed the viewport to resize the content when the on-screen keyboard opens on *Android* (`interactive-widget=resizes-content`)
- Improved the meta descriptions of the public pages and the blog posts
- Disabled the biometric authentication on all devices when generating a new *Security Token*
- Improved the language localization for German (`de`)

##### Fixed

- Fixed the flickering of the navigation items in the header for logged-in users
- Fixed the height of the dialogs on mobile
- Fixed the description of the `ROOT_URL` requirement for the server of the Model Context Protocol (MCP) (experimental)
